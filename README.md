# E-L

An always-on, private personal AI assistant. Built for the **Nebius x NVIDIA Global AI Hackathon** (Personal AI track).

E-L runs on NVIDIA Nemotron open models served through **Nebius Token Factory**, with persistent memory, reusable skills, and access only to the tools and data you choose.

> Work in progress — setup instructions, architecture and model usage will be filled in as the build lands.

## Stack

- NVIDIA Nemotron models (via Nebius Token Factory)
- Nebius Serverless (planned)
